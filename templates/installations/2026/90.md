# ZAPP

ZAPP is an electronic game by Team ZAPP.

For EMF24 our electronic game ZAPP was an installation in the bar.  This is an RGB button whack-a-mole style game which was quite popular with all age groups,  shown by the statistics we recorded over that weekend (https://adanet.co.uk/zapp24/).

We learnt a lot from EMF24, using that feedback we have built a new and improved version of ZAPP which we would like to be an installation, preferably in the bar.  We would also like to give a short talk about taking what we learnt from EMF24 and using that knowledge to build a better version of ZAPP for EMF26.

In summary the improvements we have made to ZAPP are:

*New game selection buttons at the front of the unit giving easy access to other games which can be played (BASH, MIND, SPIN & ZAPP)
*Redesigned electronics so button presses are no longer missed and the buttons do not flicker (which was very frustrating for players)
*The electronics are now enclose making the unit more robust, including moving the speakers into the side panels as someone managed to destroy the speaker during EMF24
*Redesigned website with better instructions (https://adanet.co.uk/zapp) and live statistics on the High Scores page which now works. All data is available as JSON from the website.
*Designed (using KiCad) and had manufactured (in the UK) a custom PCB to improve reliability and make soldering far easier
