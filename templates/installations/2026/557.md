# Orbs Lasertag

These light-up balls are suspended from a grid above an area.  Players use a lasertag gun to tag the orbs, with various game formats.  The grid is located above the players, ideally directly above them, but can be offset.  I'm still working on exact numbers, but i'm expecting the grid to be at least 6m x 6m.

There will be a small screen showing scores, and between 1 and 3 lasertag guns (depending how far I get with the project before EMF).  So the on-ground footprint is fairly small, enough for three people to stand comfortably next to each other while playing, plus something to hand the lasertag guns on.
