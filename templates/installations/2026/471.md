# Live LED Solar System Orrery Simulation

This installation is a modern orrery displayed on rings of 20 mm RGB LEDs. Each ring represents a planetary orbit, and a single lit LED on each ring marks where that planet is in its path around the Sun.

In true orbital time, almost nothing visibly changes over the course of a weekend, so the simulation includes a physical time‑control dial. Adjust the dial to speed up or slow down time and see how different each orbit is.

The system sits on a large 1.5 m × 1.5 m panel, turning the Solar System into an interactive data sculpture.

Designed by Richard Hawthorn
