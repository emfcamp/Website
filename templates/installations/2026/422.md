# Giant Unicorn Hat

Brian Corteil 
a super size matrix of 8 x 8 LEDs matrixes made from Pimoroni Unicorn hats. The Giant Unicorn hat is configured to be the worlds worse 64 x 64 LED display, and can display anything you can image at 64 x 64 pixels. I have written a bad web app to take a photo downsize it to 64 x 64 pixels and sent it to the Giant Unicorn Hat to be displayed on a loop.
