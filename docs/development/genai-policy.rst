Generative AI Policy
====================

Electromagnetic Field is an event for humans and we prefer human-written code.

Our priority is to encourage regular, long-term human contributors who are capable of maintaining and reviewing changes to the
EMF web codebase on an ongoing basis. Drive-by AI contributions are detrimental to this.

You must not use generative AI tools to author changes to this codebase, or to write pull requests, issues, or comments.

Generative AI is allowed for trivial code completions (< 10 lines), search, and code review.
